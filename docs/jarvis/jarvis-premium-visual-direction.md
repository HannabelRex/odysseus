# Jarvis Premium Visual Direction

## Target experience

Jarvis should feel like a personal AI command center:

- elegant
- futuristic
- focused
- readable
- powerful
- safe
- premium without being flashy nonsense

## Visual metaphor

Use the idea of an **AI mission cockpit**:

- left side: navigation and modes
- center: active mission or chat
- right side: context, memory, tools, approvals
- top: command/status layer

## Visual ingredients

### Ambient space background

A deep navy/black foundation with subtle cyan and violet aurora gradients. This creates depth without making the interface look like it is trying to sell RGB fans.

### Glass panels

Use translucent panels with soft borders, blur, and layered shadows. Panels should feel elevated but not blurry enough to annoy humans with eyes.

### Intelligent status colors

- Cyan: active/intelligent
- Emerald: healthy/connected
- Amber: loading/warning
- Red: destructive/error
- Violet: specialist/advanced mode

### Motion

Use small transitions only. Avoid heavy animation until the core UI is stable.

### Typography

Use system UI fonts for readability and a monospace stack only for code/model/status labels.

## Screens to improve next

1. Sidebar and top command bar
2. Chat mission console
3. Settings / Control Room
4. Home dashboard and quick actions
5. Context rail and approval center

## Non-goals

- Do not remove Odysseus features.
- Do not change backend behavior.
- Do not hide safety-critical controls.
- Do not make the UI so futuristic that it becomes a puzzle box.
